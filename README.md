# 📘 Решебник. Алгебра 8 класс (Макарычев)

Офлайн-решебник к учебнику Ю. Н. Макарычева и др. «Математика. Алгебра. 8 класс» (17-е изд., Просвещение, 2024) — Глава I «Рациональные дроби».

**Сайт:** https://paryginata-tech.github.io/Algebra_8_klass_GDZ/

## Что внутри

### 📖 Решебник (задания 1–267)
Все задания Главы I решены полностью и подробно, по шагам:
- §1. Рациональные дроби и их свойства
- §2. Сумма и разность дробей
- §3. Произведение и частное дробей
- Дополнительные упражнения к главе

Каждое решение включает:
- пошаговое решение (не просто ответ, а объяснение каждого действия)
- ОДЗ (область допустимых значений) — какие значения переменных исключаются и почему
- итоговый ответ

### 🧮 Решить новый пример
Калькулятор для своих примеров — не только из учебника. Умеет:
- сокращать дробь
- складывать/вычитать дроби (2–3 слагаемых)
- умножать/делить дроби
- решать уравнения (линейные, квадратные, дробно-рациональные)

Решение показывается пошагово, в том же стиле, что и в решебнике, с ОДЗ и разбором посторонних корней.

## Как пользоваться

Просто откройте [сайт](https://paryginata-tech.github.io/Algebra_8_klass_GDZ/) в браузере — на компьютере или на телефоне. Интернет нужен только один раз, при первом открытии; дальше приложение работает полностью офлайн, включая вычислительный движок для новых примеров.

На телефоне сайт можно добавить на главный экран (через меню браузера → «Добавить на главный экран» / «На экран «Домой»»), и он будет открываться как обычное приложение.

## Как это устроено

- Задания и решения — обычные данные (JS), без сервера и базы данных
- Раздел «Решить новый пример» считает через [Pyodide](https://pyodide.org/) (Python в браузере) и библиотеку [SymPy](https://www.sympy.org/) — настоящий движок символьной алгебры, работающий офлайн прямо в браузере
- Никакого бэкенда: сайт — обычные статические файлы (HTML/CSS/JS)
